---
name: tag-session
description: 00-Inbox/의 미분류 세션 메모를 읽고 프로젝트·기술
  스택·상태 태그를 붙인 뒤 해당 프로젝트 폴더로 옮긴다.
  "세션 노트 정리해줘"에 사용.
---
 
1. 00-Inbox/의 모든 노트를 나열한다.
2. 각 노트에서 어떤 프로젝트(01-Projects/ 하위 폴더 중 하나),
   어떤 기술 스택(#react, #api 등), 문제가 해결됐는지
   (#status/solved, #status/blocked)를 판단한다.
3. 적절한 태그를 붙이고 01-Projects/{프로젝트명}/으로 이동한다.
4. 이동/태깅 결과를 표로 요약해 보고한다.
