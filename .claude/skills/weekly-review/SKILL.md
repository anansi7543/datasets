name: weekly-review
description: 이번 주 새로 만들어지거나 수정된 세션 노트를 모아
  바이브 코딩 회고를 작성한다. 반복되는 에러·프롬프트 패턴은
  03-Resources/에 재사용 가능한 노트로 남긴다. "이번 주 회고
  만들어줘", "주간 회고 정리해줘"에 사용. 매주 일요일 실행 대상.
---

1. 최근 7일 이내에 생성/수정된 세션 노트(Sessions/, 00-Inbox/)를 찾는다.
2. 프로젝트별로 묶어 어떤 기능을 작업했고 어떤 문제를 겪었는지
   2~3문장으로 요약한다.
3. 반복적으로 등장한 에러나 프롬프트 패턴이 있으면, Templates/resource-pattern.md
   형식으로 03-Resources/{패턴명}.md를 실제로 생성한다. 이미 같은 패턴
   노트가 있으면 새로 만들지 않고 관련 세션 링크만 추가한다.
4. Templates/weekly-review.md 형식으로 Sessions/weekly-YYYY-Www.md
   회고 노트를 생성한다.
